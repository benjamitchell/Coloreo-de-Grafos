# Original project (2022)

`Proyecto_v3.ipynb` is the university project this repository grew out of,
kept unchanged for reference (in Spanish). The rewrite in `src/` fixes its
bugs; see "Before and after" in the main [README](../README.md) for what
changed and why. `scripts/make_figures.py` contains a faithful copy of its
annealing loop (`legacy_annealing`) used for that comparison.
